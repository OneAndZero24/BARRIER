Shared setup (DDPM)

- Unlearning recipe (main code, ablation_regions.py, same as the paper's λ sweep):
  - Random-Label objective: airplane-conditioned predictions are pushed toward the "automobile" prediction.
  - Adam, lr 1e-4, 3000 steps, no remain-set loss (weight 0).
  - Protection: k=32, two-corner boxes at the 5th/95th percentiles, infinity scale 20.
- Metrics:
  - UA (unlearning accuracy): share of the 500 airplane-conditioned samples that a ResNet-34 classifier does not call airplane. Higher means more forgetting.
  - RA (remain accuracy): ResNet-34 accuracy on 4,500 samples conditioned on the 9 other classes (500 each).
  - FID: 45k generated samples of the 9 remaining classes (guidance 2.0); lower is better. The unchanged model is about 15.2.
  - The ResNet-34 resizes images to 224×224, same as the paper and the SEMU baseline.
- λ sweep baseline (summary.csv): 4 seeds per λ (0, 1, 2, 1234).

3. Overlap analysis: protected subspace vs retain data

What: forward passes only, no training. ResNet-18 classifier with the paper's protection
settings: the protected layer is fc (the final linear layer, input dimension d=512), k=32.
Question: does the forget subspace that BARRIER protects also hold the retain data, i.e. does
protection inevitably constrain retain behaviour?

How it was computed (the repo's own setup_protection code):
1. Collect the inputs to fc for the 4,500 forget images. Run PCA centred on the forget mean μ to
   get the top-32 basis U_k, and the forget box H_f: the 5th-95th percentile range on each of
   the 32 coordinates.
2. Collect fc inputs for 10,000 retain images.
3. Compute:
   - overlap = ‖(A_r − mean A_r) U_kᵀ‖² / ‖A_r − mean A_r‖², the share of retain variance that
     lies in the protected subspace.
   - rand mean ± std: the same overlap for 10 random 32-dimensional subspaces. The expected
     value is k/d.
   - box_frac: the % of retain points whose 32 projected coordinates all fall inside H_f.
   - forget_box_frac: the same for the forget points themselves, as a reference.
4. Settings:
   - classwise: airplane forgotten.
   - random: 4,500 random training images, the repo's 10% split. These change with the seed,
     so seeds 0, 1 and 2 are used.
5. Contrast row: the earlier layer layer4.0.conv1 (d=256), which is NOT protected in the paper.

Ranges are over seeds 0, 1, 2.

┌───────────┬────────────────────┬─────┬─────────────┬─────────────┬────────┬─────────────┬─────────────┐
│  Setting  │       Layer        │  d  │   Overlap   │ Rand. basis │  k/d   │ box_frac %  │ forget_box% │
├───────────┼────────────────────┼─────┼─────────────┼─────────────┼────────┼─────────────┼─────────────┤
│ classwise │ fc (protected)     │ 512 │ 0.944-0.960 │ 0.059-0.062 │ 0.0625 │ 0.0         │ 17.6-18.3   │
├───────────┼────────────────────┼─────┼─────────────┼─────────────┼────────┼─────────────┼─────────────┤
│ random    │ fc (protected)     │ 512 │ 0.995       │ 0.059-0.063 │ 0.0625 │ 8.9-10.7    │ 9.3-11.1    │
├───────────┼────────────────────┼─────┼─────────────┼─────────────┼────────┼─────────────┼─────────────┤
│ classwise │ layer4.0.conv1 (*) │ 256 │ 0.336-0.346 │ 0.124       │ 0.125  │ 23.2-25.0   │ 22.0-22.1   │
├───────────┼────────────────────┼─────┼─────────────┼─────────────┼────────┼─────────────┼─────────────┤
│ random    │ layer4.0.conv1 (*) │ 256 │ 0.477-0.488 │ 0.124       │ 0.125  │ 25.0-25.8   │ 25.3-25.6   │
└───────────┴────────────────────┴─────┴─────────────┴─────────────┴────────┴─────────────┴─────────────┘
(*) not protected, contrast only.

Reading:
- Overlap: at fc, the forget subspace captures 94-99% of retain variance, about 15× the
  random-subspace baseline. The subspace is shared, not forget-specific, so the protection does
  constrain directions that retain data uses.
- Classwise box (0%): no retain point falls inside the forget box. The box is narrow enough to
  separate the forget class, even though only 18% of forget points fall inside it on all 32
  coordinates jointly.
- Random-forget box: about 10% of retain points fall inside, the same rate as the forget points
  themselves. Retain and forget come from the same distribution, so they can't be separated.
- Contrast layer: at the earlier, unprotected layer, overlap is much lower (0.34-0.49). The box
  captures retain and forget points at about the same rate (~23-26%), so it doesn't discriminate.

4. Drift analysis: what the protection constrains in DDPM

What: forward passes only on the existing checkpoints: the 35 runs of the paper's λ sweep plus
the λ=0 run, n=36.
Question: does λ control how much the protected layers change on retain inputs, and does that
change predict the quality loss?

How it was computed:
1. One fixed evaluation batch, saved to disk and reused for every checkpoint:
   - 512 retain images (non-airplane, with their labels) and 512 airplane images;
   - each at timesteps t ∈ {50, 250, 500, 750, 950} with fixed noise and no conditioning
     dropout.
2. Drift: for each of the 17 protected layers, its output on that batch from the unlearned model
   vs the original model, as ‖out_new − out_orig‖ / ‖out_orig‖. This is averaged over timesteps
   and over the 17 layers.
   - retain drift uses retain inputs: unwanted change.
   - forget drift uses airplane inputs: intended change.
3. Penalty: the InTAct penalty without the λ factor, recomputed for each checkpoint from the
   saved pca_info.pth (the forget subspace and boxes from the original model). It is split into
   four parts:
   - mean term;
   - orthogonal/residual term;
   - low-corner box;
   - high-corner box.
4. Spearman rank correlation across the 36 checkpoints.
5. Sanity check: the original model compared with itself gives drift exactly 0.
